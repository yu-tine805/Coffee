STUDY LEDGER
三頁：index.html / daily.html / questions.html
CSS：style.css
JS：script.js

功能：
- Home：每日中文詞彙翻頁、自動輪播、月曆、每日 1~5 努力度。
- 每日學習狀況：四科 × 五種學習狀態，問題列可按＋新增。
- 問題盒子：依科目收集問題；NO 保留；YES 會保留文字但劃線變淡。
- 所有紀錄使用瀏覽器 localStorage 保存，不需要後端。
- 建議用 VS Code 的 Live Server 預覽。

詞彙範例以臺灣教育部《重編國語辭典修訂本》為來源；Home 詞彙卡的來源連結會直接開啟教育部官方辭典。
